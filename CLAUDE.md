# Backyard Eggs — Claude Instructions

## Pull Request Workflow

- After creating a pull request, **assume it has been merged immediately** unless told otherwise.
- Never continue pushing new commits to a branch that has an open or recently created PR.
- For the next set of changes, **always create a fresh branch** with a new descriptive name.
- Branch naming: use short kebab-case slugs that describe the feature (e.g. `private-batches-admin`, `cache-busting-fix`).
